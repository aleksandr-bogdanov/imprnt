imprnt is a folder of plain **markdown** notes on your computer. You talk to your assistant in plain language, it files what matters into notes on your disk, and later it answers from your real history. Nothing it learns is lost when the chat closes.

## Install it

Two commands: the first installs the **engine**, the second makes your **vault**.

```sh title="terminal"
npm i -g imprnt
imprnt init
```

`imprnt init` does three things:

<Steps>

1. Makes the vault folder. It asks where, and Enter takes the default (`~/imprnt`). `imprnt init <path>` skips the question.

2. Writes a `CLAUDE.md` file that teaches your assistant how the vault works.

3. Registers the folder so the `imp` command can find it from anywhere.

</Steps>

If your vault already lives somewhere else (moved by hand, or made on another machine), point one variable at it and every command follows. `imprnt init` ignores this variable, so to create a new vault in a custom spot, pass the path to `init` instead.

```sh title="terminal"
export IMPRNT_VAULT=~/notes/vault
```

## Open it with `imp`

`imp` opens your assistant with imprnt wired in. Type it instead of `claude`, in any folder.

```sh title="terminal"
imp
```

There are two ways to open it. Plain `claude` stays plain, so nothing is added to a session you did not ask for.

<Aside type="tip" title="Ask this first">
<strong>{'"File a person note for me."'}</strong> You show up in almost every transcript, so a note about you lets the assistant link you to everything else from then on.

## The three things it does

You talk. Behind your words, the engine runs one of three commands.

<GettingStartedFlow />

<Aside type="note" title="You drive by talking">
You never type these commands in normal use. Your assistant runs them for you. They are here so you can see what happens and run them yourself when you want.
</Aside>

### File something: `ingest`

A source is anything: a meeting transcript, a pasted doc, a prose dump, a single fact. Hand it over.

<GettingStartedSay>

```text title="you say" frame="terminal"
You:
  Save this transcript
  and file what matters.
  [paste or drop the source]
```

</GettingStartedSay>

What happens behind the reply:

<GettingStartedIngestPath />

However dense the source, nothing thins out on the way in. Tables, numbers, dates, and exact wording are kept in full, and the one-line summary is written above them, never in their place.

### Find something: `recall`

Ask in plain words.

<GettingStartedSay>

```text title="you say" frame="terminal"
You:
  What did we decide about
  the access-platform cutover?
```

</GettingStartedSay>

<GettingStartedRecallRank />

The scoring is **BM25**, a plain formula that measures how well each note's words match your question. It is ordinary arithmetic running on your machine, with no model in the middle. It searches your real notes only: the `raw/` archive of originals is never searched, so nothing leaks from a snapshot into an answer.

### Tidy up: `check`

After filing or hand-editing, ask for a tidy pass.

<GettingStartedSay>

```text title="you say" frame="terminal"
You:
  Tidy up. What needs my attention?
```

</GettingStartedSay>
