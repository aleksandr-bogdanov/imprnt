[Whenful](https://whenful.com) is a task app. The vault holds what you know, Whenful holds what you have to do, and this plugin joins the two. Open a note and the assistant shows the tasks that belong to it, each with its title, state, and due date:

<WhenfulNote />

The tasks themselves keep living in Whenful. What you see on the note comes from a local copy on your machine, refreshed only when you ask for it.

## How it works

A **data** plugin: the bridge is two small pieces inside `plugins/whenful/`, and the whole flow between the task app and your notes looks like this:

<WhenfulBridge />

- `links.tsv` is the **join table**: one row per task-to-note link (`task_id`, `note_slug`, an optional step label). It is the only place a link is recorded. Nothing is ever written into your notes.
- `mirror/<task_id>.md` is the **local copy** of each linked task's state, one file per task.

When you ask about a note's tasks, the assistant finds the note's rows in `links.tsv`, reads each task's mirror file, and shows what it holds. Answers come from the copy on your machine, never from the server. Only `sync` crosses the network.

When something from a task deserves a permanent place in the vault, the plugin **proposes** a summary note into `proposed/`, and you approve it with `imprnt ingest --apply`. Used sparingly: a summary, never one note per task.

## Commands

```sh
# refresh the mirror from Whenful (the only network call)
WHENFUL_TOKEN=<your-device-token> imprnt whenful sync

# the same run, offline against fixtures
WHENFUL_FIXTURES=<dir> imprnt whenful sync

# integrity check (stale mirror, orphan links)
node plugins/whenful/check.js
```

`sync` calls the real Whenful API and rewrites each linked task's mirror file. If you want it periodic, schedule it yourself with cron or launchd. Nothing runs on its own, and `imprnt check --all` picks up the integrity check automatically.

## Install

```sh
imprnt plugin add whenful
```

Then add your task-to-note rows to `plugins/whenful/links.tsv` and run a sync. Remove with `imprnt plugin rm whenful`, adding `--purge` to also delete `plugins/whenful/` with your links and the mirror inside.
