The **core** is your notes plus three commands: ingest, recall, and check. Every other behavior is a **plugin** you add when you want it and remove with one line. The core never knows a plugin exists.

## How a plugin reaches Claude

A plugin is a folder with an `agent.md` fragment, instructions for the assistant. Installing it loads that fragment into your sessions, and **where it loads decides the reach**.
